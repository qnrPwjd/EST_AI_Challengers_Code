[목적] yacht dice라는 이름의 주사위 게임 웹 앱을 만들어줘

[산출물]
- 파일 구조는 네가 알아서 정해줘 (단, index.html 더블클릭으로 바로 실행되게)

[제약]
- HTML, CSS, JavaScript만 사용
- React, Node.js, npm, 외부 라이브러리 사용 금지
- 코드를 답변으로만 보여주지 말고 실제 파일 생성

[내용/디자인 요구]
- 첫 화면에서 인공지능과 플레이하는 기능, 사람과 플레이하는 기능, 게임에 대한 설명을 보여주는 기능을 버튼으로 선택할 수 있게 해줘
- 인공지능과 플레이하는 버튼을 선택할 경우와 사람과 플레이하는 버튼을 선택할 경우에 보이는 화면이 서로 다르지 않았으면 해
- 플레이 화면에서 화면 왼쪽에 각자의 족보를 확인하고 선택할 수 있는 점수판을 그려줘 
- 플레이 화면에서 보이는 주사위 디자인은 이상해 보이지 않게만 알아서 만들어줘
- 인공지능과의 게임이 끝나면 승패 여부를 간단하게 플로팅 창으로 보여줘
- 사람과의 게임이 끝나면 어떤 플레이어가 이겼는지를 간단하게 플로팅 창으로 보여줘
- 배경은 모던한 디자인으로 적절히 디자인해줘
