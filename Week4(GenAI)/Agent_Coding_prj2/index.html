게임 방법
  • 각 플레이어는 12번씩 턴을 진행합니다. 한 턴에 주사위를 최대 3번 굴릴 수 있어요.
  • 남길 주사위를 클릭해 고정한 뒤 다시 굴리거나, 왼쪽 족보를 선택해 점수를 기록하세요.
  • 모든 족보를 채운 뒤 총점이 높은 플레이어가 이깁니다. 상단 숫자 족보 합계가 63점 이상이면 +35점 보너스를 받습니다.
