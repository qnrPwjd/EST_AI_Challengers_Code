# Yacht Dice

브라우저에서 바로 즐길 수 있는 2인용 Yacht Dice 웹 게임입니다. 인공지능 대전과 로컬 2인 플레이를 지원합니다.

## 실행 방법

별도 설치가 필요 없습니다. `index.html` 파일을 더블클릭해 원하는 브라우저에서 열면 됩니다.

## 주요 기능

- AI 대전 또는 사람과의 2인 플레이 선택
- 한 턴에 최대 3회 주사위 굴리기와 주사위 고정
- 12개 족보 점수 계산 및 상단 족보 63점 이상 보너스 35점
- 최종 점수와 승패를 알려 주는 결과 창
- 데스크톱과 모바일 화면에 맞춘 반응형 UI

## 게임 방법

1. 주사위를 굴린 뒤 남기고 싶은 주사위를 클릭하여 고정합니다.
2. 필요하면 다시 굴린 후, 점수판의 파란 후보 점수를 눌러 한 족보에 기록합니다.
3. 두 플레이어가 모든 족보를 채우면 총점이 높은 플레이어가 이깁니다.

## 파일 구조

```
.
├── index.html       # 화면 구조 및 외부 파일 연결
├── css/
│   └── style.css    # UI 스타일
└── js/
    └── game.js      # 게임 로직 및 화면 제어
```

## 기술 스택

HTML, CSS, JavaScript만 사용했으며 외부 라이브러리나 빌드 도구가 필요하지 않습니다.
